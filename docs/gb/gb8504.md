# GB8504

## Graph-Break Type
*Short name describing what triggered the graph break*

Encountered mutation of an aliased input during higher order op tracing

## Context
*Values or code snippet captured at the break point*

context

## Explanation
*Explanation of why the graph break was triggered*

Higher order ops do not support mutating an input that shares storage with another input. Found in {name}

## Hints
*Hints on how to resolve the graph break*

- Clone one of the aliased inputs before the call, or stop mutating it.
- Please open an issue.
