# GB9553

## Graph-Break Type
*Short name describing what triggered the graph break*

TMA descriptor reconstruction factory mismatch

## Context
*Values or code snippet captured at the break point*

descriptor_type={descriptor_type}, factory={factory}

## Explanation
*Explanation of why the graph break was triggered*

The captured TMA descriptor factory no longer matches the class's from_tensor attribute used to reconstruct compiled descriptors.

## Hints
*Hints on how to resolve the graph break*

- Use the descriptor class's current from_tensor factory.
