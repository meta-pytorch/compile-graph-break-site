# GB1891

## Graph-Break Type
*Short name describing what triggered the graph break*

Unsafe value live across comprehension graph break

## Context
*Values or code snippet captured at the break point*

{value}, frame skipped: {format_frame_info(tx.f_code)}

## Explanation
*Explanation of why the graph break was triggered*

A context manager or local generator cannot be reconstructed safely after a comprehension graph break, so the frame falls back to eager.

## Hints
*Hints on how to resolve the graph break*

- Close the generator first, or move the comprehension into a helper.
