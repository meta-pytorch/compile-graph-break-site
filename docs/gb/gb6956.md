# GB6956

## Graph-Break Type
*Short name describing what triggered the graph break*

Sourceless _DecoratorContextManager method reconstruction unsupported

## Context
*Values or code snippet captured at the break point*

{type(value.__self__)}.{value.__func__.__name__}

## Explanation
*Explanation of why the graph break was triggered*

{type(value.__self__)} was reached without a source (e.g. via a closure cell) and {value.__func__.__name__} cannot be reconstructed safely, so Dynamo cannot safely inline it without risking a mutation on an object it can't track.

## Hints
*Hints on how to resolve the graph break*

- It may be possible to write Dynamo tracing rules for this code. Please report an issue to PyTorch if you encounter this graph break often and it is causing performance issues.
