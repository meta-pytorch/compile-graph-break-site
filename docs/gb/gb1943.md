# GB1943

## Graph-Break Type
*Short name describing what triggered the graph break*

Copying an OrderedDict with instance attributes

## Context
*Values or code snippet captured at the break point*

OrderedDict.__reduce_ex__

## Explanation
*Explanation of why the graph break was triggered*

The OrderedDict has instance attributes, or a pending dictionary write could have modified them. Dynamo cannot preserve this state when tracing the copy.

## Hints
*Hints on how to resolve the graph break*

- Copy the OrderedDict outside the compiled region.
