# GB9374

## Graph-Break Type
*Short name describing what triggered the graph break*

Reordered OrderedDict input with callback-sensitive keys

## Context
*Values or code snippet captured at the break point*

OrderedDict input snapshot

## Explanation
*Explanation of why the graph break was triggered*

Dynamo cannot restore an OrderedDict's storage order without potentially invoking user key hashing or equality.

## Hints
*Hints on how to resolve the graph break*

- Construct the OrderedDict inside the compiled function.
