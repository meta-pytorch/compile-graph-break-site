# GB1392

## Graph-Break Type
*Short name describing what triggered the graph break*

Attribute mutation on a sourced but untracked user-defined object

## Context
*Values or code snippet captured at the break point*

object={self}, name={name_str}, value={value}

## Explanation
*Explanation of why the graph break was triggered*

Dynamo encountered a sourced user-defined object that supports mutation tracking but was not registered for it.

## Hints
*Hints on how to resolve the graph break*

- This is likely to be a Dynamo bug. Please report an issue to PyTorch.
