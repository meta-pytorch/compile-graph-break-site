# GB5821

## Graph-Break Type
*Short name describing what triggered the graph break*

register_post_accumulate_grad_hook on an intermediate tensor

## Context
*Values or code snippet captured at the break point*

str(self)

## Explanation
*Explanation of why the graph break was triggered*

Dynamo cannot preserve post-accumulate hook semantics for an intermediate tensor without compiled autograd.

## Hints
*Hints on how to resolve the graph break*

- Move the hook registration outside the compiled region.
- Use compiled autograd if the hook must be registered inside it.
