# GB9613

## Graph-Break Type
*Short name describing what triggered the graph break*

current_stream device mismatch

## Context
*Values or code snippet captured at the break point*

requested={requested_type}, tracking={tracked_type}

## Explanation
*Explanation of why the graph break was triggered*

Dynamo stream mismatch: Requested '{requested_type}' stream, but SymbolicStreamState is tracking '{tracked_type}'. Dynamo only tracks streams of the default accelerator (plus stream contexts entered during tracing). Please ensure you are using the default accelerator.

## Hints
*Hints on how to resolve the graph break*

- It may be possible to write Dynamo tracing rules for this code. Please report an issue to PyTorch if you encounter this graph break often and it is causing performance issues.
