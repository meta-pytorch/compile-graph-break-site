# GB7427

## Graph-Break Type
*Short name describing what triggered the graph break*

dict subclass in torch.fx.traceback.annotate

## Context
*Values or code snippet captured at the break point*

str(annotation)

## Explanation
*Explanation of why the graph break was triggered*

Dynamo reads annotation entries directly, which would bypass overridden mapping methods (e.g. __getitem__) on a dict subclass.

## Hints
*Hints on how to resolve the graph break*

- Pass a plain dict to torch.fx.traceback.annotate.
