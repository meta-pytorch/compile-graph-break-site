# GB2842

## Graph-Break Type
*Short name describing what triggered the graph break*

dynamic value in torch.fx.traceback.annotate

## Context
*Values or code snippet captured at the break point*

str(value)

## Explanation
*Explanation of why the graph break was triggered*

Annotation values are stored as constants in the graph. Dynamic floats are specialized, but other dynamic values are not, since specializing them (e.g. a tensor size) can cause a recompile for every distinct value.

## Hints
*Hints on how to resolve the graph break*

- Compute the annotation value from configuration rather than from tensors or sizes.
