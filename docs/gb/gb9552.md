# GB9552

## Graph-Break Type
*Short name describing what triggered the graph break*

Unsupported TMA descriptor factory call

## Context
*Values or code snippet captured at the break point*

from_tensor() arguments must match its signature and defaults

## Explanation
*Explanation of why the graph break was triggered*

Dynamo supports stable TMA descriptor factories with tensor and block_shape, plus optional scalar arguments equal to their defaults.

## Hints
*Hints on how to resolve the graph break*

- Call from_tensor(tensor, block_shape) or pass only default values 
- for optional arguments.
