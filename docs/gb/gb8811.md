# GB8811

## Graph-Break Type
*Short name describing what triggered the graph break*

OrderedDict storage differs from linked keys

## Context
*Values or code snippet captured at the break point*

OrderedDict input snapshot

## Explanation
*Explanation of why the graph break was triggered*

Raw dict writes can leave storage entries without matching OrderedDict links; Dynamo cannot track their iteration order.

## Hints
*Hints on how to resolve the graph break*

- Use OrderedDict methods instead of raw dict writes such as dict.__setitem__(mapping, key, value).
- This graph break is fundamental - it is unlikely that Dynamo will ever be able to trace through your code. Consider finding a workaround.
