# GB5210

## Graph-Break Type
*Short name describing what triggered the graph break*

Constant fold with a rank-relative device

## Context
*Values or code snippet captured at the break point*

fqn(self.value)

## Explanation
*Explanation of why the graph break was triggered*

`{fqn(self.value)}` was called with the current device, whose index is only known at runtime under compile_on_one_rank, so the result cannot be folded into the graph.

## Hints
*Hints on how to resolve the graph break*

- This graph break is expected under compile_on_one_rank.
- The resumed eager call observes the running rank's device.
- Pass an explicit device if the value is the same on every rank.
